# Repository Agent Guidelines

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `gegearsyah/versieve` via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repository layout (`GLOSSARY.md` and `docs/adr/` at repo root when present). See `docs/agents/domain.md`.
